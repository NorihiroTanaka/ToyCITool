# TASK-010: ヘルスチェック・ステータスAPI

## 1. タスク概要
CIサーバーの稼働状態を外部から確認するためのヘルスチェックエンドポイントと、現在のジョブ実行状況を返すステータスAPIを実装する。

## 2. 現状の課題
*   **現状:** サーバーが正常に動作しているか確認する手段がない（HTTPレスポンスコードのみ）。
*   **問題点:** 監視ツール（Uptime Kuma等）からの死活監視ができない。実行中のジョブの有無や、キューの状態を外部から確認する方法がない。

## 3. 仕様・要件

### コアコンセプトへの適合
*   **Docker非依存:** FastAPIエンドポイントの追加のみ。
*   **容易な設定:** 設定不要。デフォルトで有効。

### 実装内容
*   **対象ファイル:**
    *   `src/api.py`: エンドポイントの追加。
    *   `src/core/job_service.py`: 実行中ジョブの状態取得メソッドの追加。

### エンドポイント

#### `GET /health`
```json
{
  "status": "ok",
  "version": "1.0.0",
  "uptime_seconds": 3600
}
```
*   サーバーが起動していれば常に `200 OK` を返す。
*   監視ツール向けの軽量エンドポイント。

#### `GET /api/status`
```json
{
  "server": {
    "status": "ok",
    "uptime_seconds": 3600,
    "started_at": "2026-04-08T10:00:00Z"
  },
  "jobs": {
    "configured": 3,
    "running": 1,
    "queued": 0
  },
  "workers": {
    "max": 2,
    "active": 1
  }
}
```
*   ジョブの設定数、実行中・待機中の件数、ワーカーの状態を返す。
*   運用時の状況把握に使用。

## 4. 優先度
**Medium**
（監視・運用の基盤となるため、本番運用前に実装しておきたい）
